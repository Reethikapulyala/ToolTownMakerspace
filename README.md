
# ToolTown Makerspace

## Project Description
ToolTown Makerspace is a Tool Library Management System
developed using Node.js, Express.js and SQLite.

## Technologies
- Node.js
- Express.js
- SQLite
- JavaScript

## Database Tables
1. Makers
2. Tools
3. Loans

## Features
- Get all tools
- Get one tool
- Add tools
- Update tools
- Delete tools
- Search tools by kind
- Validate allowed tool kinds
- Display loans using SQL JOIN

## Allowed Tool Kinds
- Power
- Hand
- Measuring

## Run the Project

Install dependencies:

npm install

Create database:

npm run setup

Start server:

npm start

## Server
http://localhost:3000/
